# Карта документации

- `journal.md` — принятые решения, даты и причины.
- `open-questions.md` — нерешённые вопросы, осознанные заглушки и недоделки.
- `ideas.md` — идеи, для которых ещё нет отдельной спецификации.
- `<направление>-spec.md` — будущая спецификация отдельного крупного направления.
- `<направление>-plan.md` — будущий план работы по этому направлению.

Новые крупные документы сразу добавлять в эту карту.
